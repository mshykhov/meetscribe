# Meetscribe

Automated meeting video processing on macOS Apple Silicon. Drop a video, get a transcript with speakers and an AI summary.

## How it works

Video in watch folder -> MLX-accelerated transcription -> word alignment -> speaker diarization -> Claude/OpenAI/Groq summary -> organized output folder

```
{date}-{topic}/
├── video.mp4
├── transcript.txt     # [00:15] SPEAKER_00: text...
└── summary.md         # topic, decisions, action items
```

Date comes from video metadata. Topic is generated by the summary backend.

## Requirements

- macOS with Apple Silicon (M1+)
- [HuggingFace token](https://huggingface.co/settings/tokens) with accepted licenses for [speaker-diarization](https://huggingface.co/pyannote/speaker-diarization-community-1) and [segmentation](https://huggingface.co/pyannote/segmentation-3.0)
- One of: [Claude Code CLI](https://docs.anthropic.com/en/docs/claude-code) (default), OpenAI API key, or Groq API key — for summaries

Python 3.12 is installed automatically by the bootstrap script if missing.

## Install

One line. Downloads the source tarball, sets up an isolated venv at `~/.local/share/meetscribe/`, bootstraps the launchd watcher + worker, and links the SwiftBar plugin:

```bash
curl -fsSL https://raw.githubusercontent.com/mshykhov/meetscribe/main/bootstrap.sh | bash
```

After install: edit `~/.config/meetscribe/.env` to set `HF_TOKEN` (required for diarization). Drop videos into your `WATCH_DIR` (default `~/Videos/OBS`); the watcher picks them up automatically.

## Usage

```bash
meetscribe ls                    # recent videos and their state
meetscribe show 42               # full details for one video
meetscribe config                # Textual TUI for editing .env
meetscribe config verify         # validate .env, exit 0/1
meetscribe web                   # local web history dashboard
meetscribe retry 42              # re-process a failed video
meetscribe reprocess /path.mp4   # force-reprocess a done video
meetscribe cancel 42             # cancel an in-flight video
meetscribe daemon status         # check launchd services
meetscribe daemon logs           # tail watcher log
```

Per-video config overrides: drop a `<stem>.meetscribe.toml` next to a video — see [docs/sidecar.md](docs/sidecar.md).

## Update

Re-run the same one-liner; bootstrap.sh detects the existing install and upgrades in place:

```bash
curl -fsSL https://raw.githubusercontent.com/mshykhov/meetscribe/main/bootstrap.sh | bash
```

Or from inside meetscribe:

```bash
meetscribe self-update
```

## Uninstall

```bash
meetscribe self-uninstall                       # keeps state.db, .env, output dir
meetscribe self-uninstall --no-keep-data --yes  # also wipes state and .env
```

A non-default `OUTPUT_DIR` (anything other than `~/docs/video`) is never auto-deleted, even with `--no-keep-data`.

## Configuration

`.env` lives at `~/.config/meetscribe/.env` (production install) or in the project root (dev mode). Edit via `meetscribe config` (validated TUI) or any text editor.

Key options:
- `HF_TOKEN` (required) — HuggingFace token with diarization licenses accepted.
- `WATCH_DIR` (default `~/Videos/OBS`) — where the watcher looks for videos.
- `OUTPUT_DIR` (default `~/docs/video`) — where summaries go.
- `TRANSCRIBE_BACKEND` — `local` (whisperx-mlx) | `openai` | `groq`.
- `SUMMARY_BACKEND` — `claude_code` (default) | `openai` | `groq`.
- See [.env.example](.env.example) for the full list with provider-specific keys.

## Dev mode

For working on meetscribe itself (clone the repo, editable install):

```bash
brew install python@3.12 ffmpeg terminal-notifier
brew install --cask swiftbar
git clone https://github.com/mshykhov/meetscribe.git && cd meetscribe
python3.12 -m venv .venv && .venv/bin/pip install -e .
.venv/bin/pip install "senko @ git+https://github.com/narcotic-sh/senko.git"
cp .env.example .env  # set HF_TOKEN
./scripts/install.sh install   # bootstraps launchd against the local .venv
```

Dev `.env` lives next to `src/`; production install reads `~/.config/meetscribe/.env`. Both are picked up automatically by `src/paths.py` (XDG first, dev fallback).

## Stack

- **WhisperX-MLX** - transcription with MLX GPU acceleration (local backend)
- **OpenAI Whisper API / Groq** - cloud transcription alternatives
- **MLX wav2vec2** - word-level timestamp alignment (local)
- **Senko** - speaker diarization via CoreML/Neural Engine
- **Claude Code CLI / OpenAI / Groq** - AI summary generation (per-stage choice)
- **launchd** - watcher always-alive, worker on-demand
- **SwiftBar** - menu bar processing status
- **terminal-notifier** - desktop notifications
- **Textual** - TUI for `.env` editing
